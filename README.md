# Revita → Temu 2.1

Три категории: https://revita.bg/alive, https://revita.bg/double-wood, https://revita.bg/natures-way.

## Какво е променено

Предишният филтър изключваше продукта дори когато твърдението беше само в рекламния текст на търговеца. Версия 2.1 изгражда фактически заглавие и описание от състава, формата и броя в опаковката. Рекламните обещания не се пренасят. Оригиналните SKU/референции остават непроменени, без REV- и без генерирани суфикси. Неактивни, липсващи или дублирани SKU се задържат за преглед.

Проверяват се отделно оригиналните изображения. Медицински твърдения върху опаковката изключват продукта. Снимки с неподкрепени здравни обещания или екологични твърдения не се експортират. Ако няма проверимо изображение или липсва потвърден произход, продуктът остава за проверка. Няма изрязване, ретуш или прикриване на надписи върху снимки.

Обозначение като Non-GMO само по себе си не се третира като екологично обещание. Това не означава, че всички твърдения върху етикет са одобрени: общите здравни обещания се задържат, ако не са проверени. Нормалното отрицателно FDA предупреждение „not intended to diagnose, treat, cure or prevent disease“ не се класифицира като обещание за лечение.

## Готовият файл

От предоставения резултат с 477 продукта е подготвен отделен Excel с 8 проверени продукта Double Wood. Неговите 8 снимки са прегледани визуално; произходът е подкрепен с конкретни страници на производителя. Останалите 469 не са обявени за забранени: те остават в отчета за допълнителни данни/проверки на произход, изображения или съответствие на категорията.

Данните за цени и наличности във файла са от предоставения резултат за 28.10.2026. Количество 20, тегло 1000 g и размери 20×20×20 cm са запазените оперативни настройки, не проверени реални складови бройки и измервания. Могат да се заменят по оригинален SKU в `product_overrides`.

## Проверени доказателства

`evidence/origin_sources.json` съдържа конкретни SKU, продуктов ID, разфасовка, източник и кратък цитат за произход от официалната продуктова страница. Доказателството се използва само за съвпадащ продукт и разфасовка, до 90 дни след проверката. Не е универсално правило „всички продукти на марката са от САЩ“.

`evidence/image_reviews.json` съдържа решения от визуален преглед по SHA-256 на снимката. Променено изображение не наследява старото решение. Наличието на преглед не заобикаля медицински или екологични проверки.

## GitHub

1. Качи съдържанието на папката в основната директория на repository, включително `.github` и `evidence`.
2. Замени старите Python файлове, `config.json`, `requirements.txt`, `tests` и `templates/temu_template.xlsx`.
3. Стартирай **Actions → Revita Temu Filtered Export → Run workflow**, `limit = 0`.
4. Изтегли **revita-temu-filtered-results** от Artifacts.

Workflow инсталира Tesseract с английски и български. Не изисква API ключ или браузър. Нормалното изпълнение обхожда актуалните три категории. Поддържат се JSON списъци, всички страници, обновяване на кеша и проверка на продуктов ID при грешен SEO canonical адрес.

Локално:

```bash
python -m pip install -r requirements.txt
python -m unittest discover -s tests -q
python revita.py --refresh
```

За обработка на вече изтеглен резултат, без ново обхождане на категориите:

```bash
python revita.py --from-results revita-temu-filtered-results.zip --output output-reprocessed
```

Изображенията без актуален локален кеш се изтеглят за проверка. Цените/наличностите при този режим остават тези от моментната снимка.

## Резултати

- `TEMU_REVITA_FILTERED_001.xlsx`: попълнен оригинален Temu шаблон само с преминалите проверки записи.
- `included.csv`, `excluded.csv`, `screening.json`: решения, оригинални SKU и доказателства.
- `images.csv`, `image_screening.json`, `image_review.html`: проверка на снимките.
- `coverage.json`, `errors.csv`, `http_attempts.json`: контрол на обхождането и технически грешки.
- `summary.json`: ясни броеве за включени и задържани продукти.

OCR е поправен да чете TSV без интерпретация на кавички като многоредови CSV полета. Кешът му е обновен. Добавени са поправки за мио-инозитол и за избягване на объркване на „магнезиев комплекс“ с „витамин B-комплекс“.

Този инструмент не удостоверява регистрациите за храни, безопасността на всяка съставка/доза, произхода на конкретна производствена партида или окончателното одобрение от Temu. Непотвърдени факти не се измислят. Запазени са структурата, dropdown списъците, скритите листове и резервираните редове на новия шаблон.
