# 1.1 — 12.10.2026

## Причини за непълния резултат

Приложеният резултат съдържа 165 открити адреса, 41 изнесени продукта, 124 грешки `Document is empty` при продуктови страници и 17 грешки `Listing container absent` при категории/страници. `limit` не е бил зададен. И седемте марки имат непълно обхождане.

С отделни диагностични HTTP заявки бяха възпроизведени:

1. `/alive?page=2` и `/natures-way` могат да върнат `application/json`. Старият код подаваше този JSON на HTML parser, вместо да извлече `rendered_products`.
2. Адресът на Alive Diabetic връщаше HTTP 200 с 0 байта. С уникален параметър `_revita_export` същият продукт върна пълен HTML. Промяна само на User-Agent не възстанови чистия адрес. Това е установеното поведение; архивът не показва кой слой на сайта/кеша създава празните отговори.
3. Продуктовите списъци съдържат и реални адреси под `/promo-paketi/`, които старият филтър изключваше.

## Корекция

- Категории чрез `ajax=1`, с обработка на JSON фрагментите и броячите на страниците.
- Уникален параметър за обновяване на кеша във всяка мрежова заявка.
- Разпакетиране на gzip/deflate и проверка на съдържанието преди кеширане.
- До 5 опита за празни/невалидни HTTP 200 отговори; невалидният стар локален кеш се игнорира.
- Всички страници от 1 до последната, дори при меню с многоточие.
- Всички продуктови адреси от основните продуктови карти, включително пакетите.
- Сверяване на уникалните продукти за марка с `pagination.total_items` и диагностика за остатъчни грешки.
- Запазена настройката за празни Brand/Manufacturer при Alive/Nature's Way, Double Wood и Bärbel Drexel; продуктите остават в общия файл.

## Проверка

Регресионните тестове използват реалните JSON отговори: втората страница Alive има 17 продукта, включително един под `/promo-paketi/`; JSON за Nature's Way посочва 318 продукта и 14 страници. Допълнително се симулират HTTP 200 с празно тяло, невалиден стар кеш, gzip и грешен номер на страница.

Провереният на сайта коригиран HTTP клиент възстанови конкретния неуспешен продукт и един промоционален пакет. Няма пълно сканиране на каталога по време на разработката и няма гаранция срещу бъдещи промени/блокиране от сайта.
